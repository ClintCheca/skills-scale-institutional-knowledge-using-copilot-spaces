## Add a repository as a source to your Copilot Space

1. Open **GitHub Copilot** and go to **Spaces**.
2. Open an existing Space (or create a new one).
3. In the Space, navigate to **Sources**.
4. Click **Add source**.
5. Select **Repository**.
6. Search for and choose the repository you want to add.
7. Confirm and save (approve access if prompted).
8. Wait for indexing to finish before asking repository-specific questions.

### Tips

- Add repositories that contain trusted documentation and code used by your team.
- Keep source repositories current so Copilot Space responses stay accurate.
- Combine repository sources with docs/markdown references for richer context.
